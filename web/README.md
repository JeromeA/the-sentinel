# The Sentinel Remaster

Open `index.html` in desktop Chrome or Firefox with WebGL 2 enabled. Keep this folder intact. It runs offline from a local file; no build, server, npm or extra installation is required. Three.js is vendored in `vendor/`, and the game assets are embedded in `src/asset-data.js`.

Dismiss the title to preview the highest known level. Choose another level from the left bar, or use Up/Down. Click the preview or press Enter to play.

Mouse movement looks around; left click absorbs and right click transfers. T/B/R create trees/boulders/robots; H hyperspaces; Tab shows the overview; Escape pauses. Progress is saved in the browser. Reset clears the known-level list and result markers.
